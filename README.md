# student-performance-analysis

Student Performance Analysis System

A Machine Learning based web application for predicting and analyzing student academic performance using Streamlit.

🚀 Features
Final Grade Prediction
Performance Category Prediction
Interactive EDA Dashboard
Student Recommendations
Dark / Light Theme
Modern Responsive UI
🤖 Machine Learning
Linear Regression
Random Forest Regressor
Logistic Regression
Random Forest Classifier
SMOTE for class balancing
🛠 Technologies Used
Python
Streamlit
Scikit-learn
Pandas
NumPy
Plotly
Seaborn
Matplotlib
